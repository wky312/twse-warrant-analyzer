# 台股權證分析 — 設計簡報

單頁式 Streamlit App。使用者輸入標的股票代碼、目標價與目標達成日期，
工具回傳「在這個情境下，哪些權證能獲利」的排序，並提供 Black-Scholes
合理價計算機輔助下單。

目標使用者：股票權證實際下單者（非機構），痛點是盤口稀疏、心算合理價困難。

---

## 頁面結構（top → bottom）

### 1. 頁首
- Logo + 標題：「📈 台股權證分析」（H1）

### 2. 輸入列（5 欄並排）
| 欄位 | Widget | 預設值 | 備註 |
|---|---|---|---|
| 標的股票代碼 | text_input | `2330` | 例：2330（台積電）、2454（聯發科） |
| 方向 | radio（橫向） | 認購 | 認購 / 認售 |
| Top N | slider | 5 | 範圍 3 ~ 10 |
| 目標標的價 | number_input | 2800.00 | 使用者預期的標的價 |
| 目標達成日期 | date_input | 今天 + 60 天 | 上限：今天 + 365 天 |

底下一行小字 caption：「距今 60 個日曆日　|　資料來源：元大權證網」

### 3. 主行動按鈕
- 「🔍 開始分析」橘紅色 primary button，full width

### 4. 合理價計算機（折疊 expander，預設展開於初始畫面、收合於分析後）
標題：「🧮 合理價計算機（BS）」

**內部結構**（兩種模式）：
- 模式 A：「從候選清單選」（分析後可用，預設）→ selectbox
- 模式 B：「手動輸入」（永遠可用）→
  - 第一列：方向（radio）/ 履約價（number）/ 行使比例（number, 4 位小數）
  - 第二列：剩餘天數 / 權證市價（可選）/ IV %（預設值）

**共用計算區（兩模式共用）**
- 第一列三欄：現在標的股價 / IV % slider / 敏感度表步長
- 第二列兩欄：無風險利率 % / 股息率 %

**輸出**（三欄 metric）：
- BS 合理價（已對齊 tick）
- 📥 買進可掛
- 📤 賣出可掛

下方兩行小字：
- 市價 X | 偏差 🟢/🔴 ±Y%（市價相對合理價便宜/偏貴）
- 內含值 0.000 + 時間價值 1.472 | 到期 88 天

最底：敏感度表（dataframe，7 列）
- 欄位：股價變動 / 標的價 / 合理價 / 買進掛 / 賣出掛
- 列：-3× / -2× / -1× / 0 / +1× / +2× / +3× × 步長

### 5. 提示訊息（僅初始畫面顯示，分析後消失）
> 👆 想看完整分析？輸入標的、方向、目標價/日期 → 點上方「🔍 開始分析」

### 6. 資料來源狀態列（分析後）
綠色 success bar：`資料來源：yuanta　|　原始候選：942 檔`
（可能伴隨 info：`[穩健型] X 檔因缺 Greeks/IV 被排除`）

### 7. 頂部 KPI 卡（分析後，三欄 metric）
- 反推標的現價（如 2310.0）
- 目標價 (60 天後)（如 2800）
- 預期漲跌幅（如 +21.2%）

若方向選錯（call 但目標 < 現價、put 但目標 > 現價）→ 黃色 warning。

### 8. 情境模擬區
標題：「🎯 情境模擬：到 2026-07-06 達 2800（距今 60 日）」H3

下方小字 caption：`已過濾：到期早於目標日 5 檔　|　成交量不足 99 檔　|　價差過寬 40 檔　|　達標仍虧損 17 檔`

綠色 success：`✅ 通過情境過濾：78 檔　|　按達標報酬率排序`

**情境表（dataframe，前 20 列）** — 凍結左二欄（權證代碼/權證名稱）
欄位：權證代碼 / 權證名稱 / 成交價 / 等效Δ / IV% / 槓桿 / 履約價 / 行使比例 / 價內外% / 天期 / 成交量(張) / 損益兩平 / 達標權證價 / **達標報酬%** / 平盤報酬% / 跌5%報酬% / 跌10%報酬%

### 9. 達標報酬率前 3 強卡片（H5）
每張卡 3 欄：
- **左欄**：metric「#N 達標報酬 +XXX.X%」+ 權證代碼（粗體）+ 權證名稱
- **中欄**：履約 / 天期、現價 → 預期、損益兩平 + 距 BE
- **右欄**：⚠️ 平盤不動 X% / ⚠️ 跌 5% X% / ⚠️ 跌 10% X%

### 10. 候選清單表（H3）
`🗂️ 候選清單（通過硬過濾，239 檔）`，dataframe 凍結左二欄

欄位：權證代碼 / 權證名稱 / 認購售 / 成交價 / 漲跌 / 漲跌幅% / 成交量 / 履約價 / 行使比例 / 剩餘天數 / 價內外% / 買賣價差比% / 實質槓桿 / 成交價隱波% / 等效Δ / 流通在外比例%

### 11. 個別權證基本資料（H3）
selectbox + 兩欄 monospace 文字區

左欄：上市日期 / 最後交易日 / 到期日期 / 發行型態 / 最新發行張數 / 流通在外張數比例 / 最新履約價 / 最新行使比例

右欄：買價隱波 / 賣價隱波 / 原始 Delta / 等效 Delta / Theta / 剩餘天數 / 價內外程度 / 實質槓桿 / 買賣價差比

### 12. 候選分佈散佈圖（H3）
`📊 候選分佈：IV × |等效Δ|`
- X 軸：隱含波動度 %
- Y 軸：|等效Δ| (0~1)
- 氣泡大小：成交量
- 氣泡顏色：槓桿（Viridis 色階）

### 13. 計算邏輯說明（折疊 expander）
`ℹ️ 計算邏輯與 Delta 說明` — markdown 表格 + 公式說明

## 設計風格目標

- **資訊密度高但不擁擠** — 此工具是「下單前的決策面板」，非 marketing 頁
- **數字優先**：metrics 大字、明確正負色（🟢綠 = 利好、🔴紅 = 警示、+/- 號明顯）
- **表格為主視覺** — 候選表 / 情境表是核心，可考慮表格內報酬欄做 heatmap
- **行動一致性**：「🔍 開始分析」是所有流程入口，視覺要顯眼
- **行動裝置**：目前 Streamlit layout="wide"，桌機優先；行動裝置可接受 stack 排版

## 資料說明（給設計師）

- **等效 Delta**：教科書 0~1 標準化 Delta（=原始 Delta / 行使比例）
- **達標權證價**：BS 模型推算「目標日達目標價時權證的合理價」
- **內含值 + 時間價值**：權證價 = 內含 + 時間，BS 公式拆解
- **損益兩平**：認購 = 履約價 + 權證/行使比例；認售反向
- **tick**：台股升降單位（< 10 → 0.01，≥ 1000 → 5 元等共 6 段）
